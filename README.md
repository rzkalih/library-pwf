**Simulasi Perpustakaan Sederhana dengan PHP**


**Deskripsi**

Project ini merupakan tugas sederhana untuk menerapkan konsep Object-Oriented Programming (OOP) menggunakan PHP dengan studi kasus sistem perpustakaan.

Project ini mensimulasikan pembuatan objek buku, member, peminjaman buku, serta digital book. Selain itu, project ini menerapkan konsep Inheritance dan Method Overriding dalam OOP.

**Fitur**

1.Membuat objek Book

2.Membuat objek Member

3.Melakukan simulasi Peminjaman

4.Membuat Digital Book

5.Menampilkan informasi dari setiap objek

6.Menerapkan konsep Inheritance

7.Menerapkan konsep Method Overriding
